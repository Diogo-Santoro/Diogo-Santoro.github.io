## 2024-11-01 - Respect prefers-reduced-motion globally and in JS animations
**Learning:** JS-driven interactive elements and CSS transitions/animations should be disabled or effectively canceled for users who prefer reduced motion. For CSS, applying a global `(prefers-reduced-motion: reduce)` media query that sets `animation-duration: 0.01ms !important;` and `transition-duration: 0.01ms !important;` effectively removes the motion without preventing `transitionend` and `animationend` events from firing (which can break React components). For JS logic, early returns using `window.matchMedia('(prefers-reduced-motion: reduce)').matches` provide a robust solution.
**Action:** Always implement a global CSS reduction and apply early returns in JS event listeners driving animations when accommodating user preferences for reduced motion.
